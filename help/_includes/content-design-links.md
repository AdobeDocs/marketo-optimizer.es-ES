# Creación de contenido: seguimiento de vínculos

El panel de seguimiento de vínculos proporciona una vista centralizada en la que puede localizar fácilmente cada dirección URL en el contenido. Haga clic en el icono _[!UICONTROL Vínculos]_ ( ![Mostrar vínculos](../user-guide/assets/do-not-localize/icon-links.svg) ) que aparece a la izquierda para mostrar todas las direcciones URL vinculadas en el contenido. Son los vínculos dentro de los componentes de texto, botón o imagen.

Para definir el seguimiento de un vínculo de contenido enumerado, haga clic en el icono _Editar_ ( ![Editar icono](../user-guide/assets/do-not-localize/icon-edit.svg) ) y modifique el **[!UICONTROL Tipo de seguimiento]** o **[!UICONTROL Etiqueta]**.
